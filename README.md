# 생선 합치기 매크로 (Android)

화면에 보이는 **같은 그림(물고기 / 총)끼리 자동으로 끌어다 합치는** 매크로 앱입니다.

## 어떻게 동작하나요
1. 접근성 서비스로 화면을 캡처합니다. (Android 11+)
2. 내가 등록한 그림(템플릿)을 OpenCV 템플릿 매칭으로 화면에서 찾습니다.
   - 좌우로 뒤집힌 물고기도 같이 찾습니다.
   - **겹침 보정**: 일부가 가려져도 그림 중앙 부분만으로 한 번 더 찾습니다. (감도 슬라이더로 조절)
   - 한 개체가 두 마리로 잡히지 않도록 가까운 후보는 하나로 합칩니다.
3. 같은 종끼리 가장 가까운 쌍을 만들어 드래그로 합칩니다. 한 번 캡처할 때 여러 쌍을 연속으로 처리해서 빠릅니다.
4. 물고기 / 총은 대상을 전환해서 따로 사용합니다. (그림 목록, 인식 영역이 각각 저장)
5. **총은 등급(색상) 모드**: 총 모양이 아니라 타일 바탕색(D 갈색, C 주황, B 하늘, A 연두 …)으로 같은 등급을 찾습니다.
   등급마다 타일 1칸씩만 등록하면 되고, 비슷한 색(B 하늘 / X 청록)은 칸 색과 가장 가까운 등급 쪽으로만 배정해 섞이지 않게 했습니다.

## GitHub에서 APK 받기
1. GitHub에서 새 저장소(Repository)를 만듭니다.
2. 이 폴더의 파일을 전부 올립니다. (`.github` 폴더 포함. 웹에서 "Add file > Upload files"로 드래그해도 됩니다)
3. 저장소의 **Actions** 탭 → `Build APK` 실행이 끝날 때까지 기다립니다. (처음엔 5~10분)
   - 자동으로 안 돌면 Actions 탭에서 `Build APK` → `Run workflow`
4. 완료된 실행을 열고 아래쪽 **Artifacts**의 `fish-merge-macro-apk`를 받아 압축을 풀면 `app-debug.apk`가 있습니다.
5. 폰에 설치합니다. ("출처를 알 수 없는 앱" 허용 필요)

빌드가 실패하면 Actions의 빨간 단계 로그를 복사해서 알려 주세요.

## 폰에서 처음 설정
1. 앱을 열고 **① 접근성 서비스 켜기** → 목록에서 "생선 합치기 매크로"를 켭니다.
   - 스위치가 회색이면: 설정 > 앱 > 생선 합치기 매크로 > 우측 상단 ⋮ > **제한된 설정 허용** 후 다시 시도
2. 게임 화면으로 이동하면 화면 왼쪽 가장자리에 작은 패널이 떠 있습니다. (☰ 부분을 끌면 이동, 탭하면 접기)
3. **📷 그림 등록**: 정지된 화면이 나타납니다. 합칠 그림을 **종류마다 하나씩** 드래그로 감싸 저장하고 **완료**.
   - 겹치지 않은 깨끗한 개체를 고르세요. 몸통이 사각형 안에 딱 들어오게 감싸는 게 좋습니다.
   - 레벨이 높아져서 나중에 나오는 종류는 그때 다시 등록하면 됩니다.
4. (선택) **▭ 인식 영역**: 수조(또는 총 영역)만 지정하면 더 빠르고 오인식이 줄어듭니다.
5. **▶ 시작**. 멈출 때는 **■ 정지**.

## 조절 팁 (앱 메인 화면 설정)
- 겹친 그림을 못 잡는다 → **감도** 낮추기 (62% → 55%), 겹침 보정 켜기
- 엉뚱한 그림끼리 합치려 한다 → 감도 올리기, 비슷한 종은 더 깨끗한 그림으로 다시 등록
- 더 빠르게 → 합칠 쌍 수 늘리기, 드래그 시간 줄이기(80~110ms), 인식 해상도 낮추기(40%)
- 드래그가 안 먹힌다 → 드래그 시간 늘리기(150~250ms)
- 더 합칠 수 없는 최고 등급 그림은 등록하지 않거나 목록에서 "사용"을 꺼 주세요.

## 알아둘 점
- 화면 캡처가 초당 약 3회로 제한되어 있어서, 한 번 캡처로 여러 쌍을 처리하는 방식으로 속도를 냅니다. 물고기가 헤엄치며 움직이므로 쌍 수를 너무 크게 하면 빗나갈 수 있습니다.
- 패널은 합치는 영역 위에 겹치지 않게 옮겨 두세요.
- 게임 약관에서 매크로를 금지할 수 있으니 본인 책임으로 사용하세요.
